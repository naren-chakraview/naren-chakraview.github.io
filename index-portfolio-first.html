Working with AI

The Chakraview AI Dev Model.

Every reference architecture above was built using the Chakraview AI Dev Model — an open framework for contract-first, AI-agent-driven software development. It's the methodology that makes humans and AI agents productively collaborate on complex systems.

Learn More ↗
📋

Contracts Before Code

No service exists without a contract that defines what it must do. SLA targets, domain invariants, and event schemas are versioned YAML — reviewed in PRs, enforced in CI.

🤖

Humans Define, Agents Execute

Senior engineers author contracts. AI agents implement from them. The separation is structural: contracts/ is human-only; services/ and infrastructure/ are agent-built.

📊

Measure Before You Claim

No service ships without instrumentation that proves it meets its SLA. Histogram boundaries derived from targets. SLO queries reference metric names mandated in context documents.

↺

Intent Through a Gate

Business signals pass through Intake/Triage: an interactive dialogue where agents challenge assumptions, surface edge cases, and produce contracts before implementation. The SDLC loop closes on itself.

6

Six Defined Personas

Human Domain Expert · Documentation Agent · Script Authoring Agent · Script Executor · Implementation Agent · Architectural Compliance Agent. Each has explicit accountability, defined tooling, and human review gates.

↺

Continuous SDLC Cycle

Business intent enters through Intake/Triage. A triage routing table classifies intent and routes it to the right phase. Phase 7 detects change signals from the running system and re-enters them as the next Intake input. The loop never opens.

⊟

Contracts Are the Boundary

Humans author contracts. Agents implement from them. No agent output is accepted without a corresponding contract. SLA targets flow to SLO definitions and Prometheus alerts without manual translation.
